# 小隐 · 《解锁大自然的隐身魔法》课程智能体

> 幼儿园大班科学（自然探究）课程配套智能体。
> 角色：**AI森林小博士·小隐**（原创圆润小机器人，暖白机身 / 森林绿外壳 / 发光眼睛 / 头顶叶片 / 随身放大镜）。

---

## 一、这是什么

一个可以**在课堂上真实使用**的课程智能体，包含四部分：

| 组成 | 说明 | 入口 |
|---|---|---|
| 学生端网页 | 手机 / 平板扫码即用；文字、语音、拍照三种提问方式；森林绿 + 暖白卡通风格，大按钮大字号 | `http://<地址>/` |
| 扫码入口单页 | 课堂投屏 / 打印用，二维码指向实际可访问地址（自动拒绝 localhost） | `http://<地址>/scan` |
| 教师端网页 | 教学环节切换、对话、能力状态、二维码与网络自检 | `http://<地址>/teacher` |
| Windows 桌面悬浮窗 | **原生桌面窗口**（置顶、可拖动、左击开对话框、右击菜单含退出），可在 PPT / 希沃 / PDF 全屏时置顶显示 | `启动小隐.bat` |

课程适配：围绕教案 9 个教学环节组织知识库，重点支持**闯关前幼儿提问答疑**、**平板探究中提问**、**闯关后收获分享**；
语言简短适龄，**每次只追问一个问题**，**先引导观察再解释**；准确区分**保护色 / 拟态 / 变色**，并纠正
“变色龙能随意变成任何背景颜色”“雪豹是纯白色”等常见误区。

## 二、快速开始（Windows，零依赖）

> 运行时**不需要安装任何第三方库**（后端、桌面端、头像渲染、二维码编码全部为 Python 标准库实现）。
> 仅需 **Python 3.8+**（开发与验证使用 3.13）。

```bat
:: 方式一：桌面悬浮窗（推荐，含教师对话框）
双击  启动小隐.bat

:: 方式二：只要网页服务（浏览器模式）
双击  启动课堂服务.bat

:: 方式三：没有密钥时的演示模式（规则回答，界面明确标注“非真实 AI”）
双击  启动演示模式.bat
```

命令行等价写法：

```bash
python -m backend.server                 # 后端（默认 0.0.0.0:8000）
python desktop/launcher.py               # 桌面端（自动拉起后端 + 悬浮窗）
python desktop/launcher.py --port 8010 --demo
```

浏览器打开：

- 学生端：`http://127.0.0.1:8000/`
- 扫码页：`http://127.0.0.1:8000/scan`
- 教师端：`http://127.0.0.1:8000/teacher`

## 四、安全与隐私（重要）

- **密钥只保存在后端私密配置或环境变量**：`config/config.json`（已 `.gitignore`）或环境变量；
  不进入网页、二维码、日志、导出物或 GitHub。日志输出经 `config.redact()` 脱敏。
- **未配置即明确显示“未配置”**：不会用固定回答或模拟接口冒充真实 AI。
  演示模式（`--demo`）的回答会在界面上标注“演示内容（非真实 AI）”。
- **学生隐私**：学生端匿名会话，不采集姓名/手机号；**照片原图不落盘**，仅在内存中分析后丢弃，
  只保留文字观察结果。
- **不修改系统设置**：本程序不修改代理、防火墙、注册表安全项、安全组。
- **不入库内容**：原始课件 PDF/DOC、资料渲染图片、学生会话数据、学生照片与录音。
